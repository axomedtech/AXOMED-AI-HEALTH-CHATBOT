## 🚀 About

AXOMED AI Symptom Checker is a simple AI-powered healthcare chatbot built using Python and Machine Learning.  
The system predicts possible medical conditions based on user symptoms and displays confidence scores with top predictions.

---

## ✨ Features

- 🧠 AI Symptom Prediction
- 📊 Top 3 Disease Predictions
- 📈 Confidence Score System
- 💬 Interactive Chatbot
- ⚡ Fast Terminal-Based AI
- 🩺 10 Supported Medical Conditions

---

## ⚙️ Technologies Used

- Python
- Scikit-learn
- NumPy
- Logistic Regression

---

## ▶️ Run Project

```bash
pip install scikit-learn numpy
python app.py
```
