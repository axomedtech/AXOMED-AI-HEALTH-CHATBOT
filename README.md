# 🧠 AI Health Chatbot (ML)

Simple Python ML chatbot that predicts fever, cold, and headache using CountVectorizer + Logistic Regression.

## 🚀 Run
pip install scikit-learn  
python chatbot.py  

## 💬 Example
You: I have fever  
AI: fever  

You: sneezing  
AI: cold  

## ⚠️ Note
Not a medical tool, only for learning ML basics.
